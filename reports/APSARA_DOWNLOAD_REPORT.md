## 3. 技术实现（本次实际上手路径）

### 3.1 绕过主站风控（x5sec）
- 主站对 `curl` 直抓有 x5sec 验证码拦截；但对**真实浏览器放行**。
- 本环境用系统预装的 **Google Chrome 144**（`/usr/bin/chromium`），通过 Python **Playwright** 以无头模式加载源页，
  正常渲染、未被拦截（实测 `BLOCKED_LIKELY=False`，首页即抓到 21 条直链）。
- 文档实际托管在阿里云 **OSS 公开读**（`apsarastackdocument.oss-cn-hangzhou.aliyuncs.com`），
  直链可 `curl`/`requests` 直连下载，完全绕开主站风控。

### 3.2 分页遍历
- 页面为前端 JS 分页（阿里 `@alifd/next` 组件），共 **21 页**。
- 通过定位「下一页」按钮（`button.next-next`）逐页点击，每页用 DOM 提取
  `a[href*='oss-cn-hangzhou']` 的直链，并从父节点文本读取版本号（`V3.18.x`）。
- 累计抓取 21×21+3 = 421 条，URL 去重后 421 条唯一。

### 3.3 OSS 直链格式
```
https://apsarastackdocument.oss-cn-hangzhou.aliyuncs.com/{编码路径}/{文件名}.pdf
```
- 路径中文为 URL 编码（如 `%E5%9B%BD%E9%99%85%E7%89%88%E6%96%87%E6%A1%A3` = 「国际版文档」）。
- 公开读，无需签名、无需登录，可批量直连下载。

### 3.4 版本去重
- 核心身份 = 文件名去掉「前缀(阿里云 专有云) + 版本号 + 日期」后的剩余部分（见 `dedup.py` 的 `core()`）。
- 同一核心身份多版本时，仅保留最高版本（V3.18.6 > V3.18.3 > V3.18.2），删除低版本。
- 复现结果：核心身份组 **287**、保留 **287**、删除低版本 **132**。
