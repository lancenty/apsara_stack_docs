# 1.云接入网关

云接入网关旨在为客户提供快速上云和灵活构建混合云等基于特定场景的网络服务，可满足云基础设施从私有云或公共云向混合云演进的差异化需求。

<a id="section-2"></a>

# 2.产品详情

云接入网关旨在为客户提供快速上云和灵活构建混合云等基于特定场景的网络服务，可满足云基础设施从私有云或公共云向混合云演进的差异化需求。

**开放网络服务平台**

基于NFV的三方虚拟网络服务（如负载均衡、防火墙、网络性能管理等）提供遵循ETSI标准的生命周期管理平台，实现了三方虚拟网络服务产品的标准接入、高可用、快速伸缩以及高效运维支撑，为客户提供生态合作伙伴的虚拟网络及安全服务。主要的功能有：

- 虚拟网络服务集初始化

- 虚拟网络服务集群管理

- 网络引流策略管理

- 虚拟网元健康检测、故障隔离

**算力平台网络**

通过对CPN网络中节点的诊断、性能分析、性能监控、网络设备纳管、网络监控，为运维提供充分的数据依据，以帮助管理员更好地理解和管理网络性能与故障问题。

**智算服务器接入VPC**

智算服务器通过算力平台接入网关（专用CHSW设备）接入VPC，实现智算服务器资源的统一管理的。系统提供实例管理、操作历史记录、裸机网络管理、运维配置等操作，以完成算力平台接入网关的日常运维工作。

<a id="section-3"></a>

# 3.产品价值

云接入网关为专有云客户提供完整、高效、安全、易用、可视的网络服务。

**开放网络服务平台**

提供开放网络服务平台能力，为生态网元提供标准接入、快速部署、高效运维支撑。

- 自动化部署：通过标准化、模型化支持生态合作伙伴虚拟网络设备的自动化部署。

- 高可靠性：支持虚拟网络设备A/S高可用集群模型，主备切换自动进行流量切换。

- 集中式管理：将合作伙伴虚拟网络设备集中部署在独立VPC中，实现集中式管理并降低部署成本。

**算力平台网络**

提供智算场景网络接入能力，具有高性能、易运维、灵活接入、兼容性强、安全优势。

- 高性能：支持基于RoCEv2的RDMA网络，支持物理双平面/虚拟多平面、多轨道方案部署。

- 易运维：支持主机侧20+项的一键巡检项，支持覆盖通讯库、带宽、时延的性能分析测试工具，主机侧和网络侧监控告警覆盖全面，整网易运维。

- 灵活接入：支持计算节点/存储节点双上行接入存管网，支持计算节点单上行/双上行接入计算网，覆盖当前主流GPU网卡的接入方式。

- 兼容性：交换机兼容支持华三、锐捷。GPU支持英伟达GPU、海光DCU、昇腾NPU。

- 安全：支持基于ACL的租户隔离，多租流量安全隔离。

**智算服务器接入VPC**

提供智算服务器接入VPC的能力。

- 兼容：对智算服务器零侵入，支持服务器借助转发网关接入VPC网络。支持客户利旧存量服务器，实现投资保护。

- 统一：与阿里云VPC产品集成，实现ECS、智算服务器联通及资源统一管理。

- 易用：与智算服务器管理对接，对智算服务器资源进行统一管理，按需分配。随智算服务器资源分配自动完成智算服务器租户网络配置。

- 安全：支持智算服务器网络多租户隔离，智算服务器网络与云平台底层网络隔离。
