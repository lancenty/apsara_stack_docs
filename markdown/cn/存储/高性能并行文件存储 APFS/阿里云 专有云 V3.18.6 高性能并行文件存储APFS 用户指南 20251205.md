# 1.什么是APFS文件系统

**产品概述**

高性能并行文件存储APFS（ApsaraStack Parallel File System）是以云定义的分布式并行文件系统，具备智算场景下大规模并行训练所需的高性能，以及智能化数据管理、可靠的安全保障、灵活的部署形态、资源弹性扩展等特点。适配海光DCU、Ascend GPU加海光存储集群的场景。

## 2.3. 使用限制

本文介绍APFS文件系统使用限制。

- 仅支持性能型文件系统，最大总容量为25 PiB。

- 仅支持通过裸金属算力平台BMCP控制台挂载至BMCP算力集群。

- 默认自动创建挂载点，不支持额外创建挂载点。

- 文件系统的扩容需要在非数据读写的状态下进行。

- 不支持集群缩容。

## 3.1. 管理文件系统

**查看文件系统**

**前提条件**

已创建APFS文件系统。

**操作步骤**

1. 登录APFS文件存储控制台。

2. 在APFS列表页，可以根据**文件系统ID**或**文件系统名称**筛选查找文件系统。

3. 在文件系统列表页，单击**监控**列的 <img src="assets/e7bea77177c334a2f3db93642f19b939.jpeg" width="16" alt=""> 图标，可查看该文件系统的容量、带宽、读写iops等指标数据。

4. 在文件系统列表页，单击文件ID或单击**操作**列的**详情**，可查看文件系统的基本信息。

5. 在**基本信息**页面，可查看文件系统ID、状态、规格、容量等信息。

**删除文件系统**

**前提条件**

- 删除文件系统前需要先取消文件系统挂载。

- 文件系统删除后不可恢复，删除前请确保已完成数据备份。

- 文件系统删除后不会立即释放资源，将于7天后释放磁盘占用空间。

**操作步骤**

1. 登录APFS文件存储控制台。

2. 在文件系统列表中**操作**列单击**删除**。

3. 在弹出的对话框里单击**确定**。

**修改文件系统描述信息**

1. 在文件系统列表页中找到目标文件系统，将鼠标悬浮至**文件系统名称/ID**列，单击 <img src="assets/d07afc93fc4f611273598af8fa6dd9f9.png" width="14" alt=""> 图标。

2. 在弹出的对话框中输入新的描述信息。

3. 单击**确定**。

> **说明**
>
> 文件系统描述信息，长度限制为2-128个字符，以大小写字母开头，支持数字和"_"、"-"、":"特殊字符，不能以 `http://` 和 `https://` 开头。

## 3.2. 扩容文件系统

**前提条件**

1. 已创建APFS文件系统。

2. 文件系统处于非读写状态。

**操作步骤**

1. 登录APFS文件存储控制台。

2. 在文件系统列表页中选择目标文件系统，单击右侧操作列的**扩容**。

3. 在文件系统扩容详情页，选择**新的总容量（TiB）**。

   > **说明**
   >
   > 新的总容量不能低于当前总容量，不能超过当前集群的最大总容量。

4. 单击**确认订单**，完成文件系统的扩容。

## 3.4. 数据流动

本文介绍如何设置APFS与对象存储OSS之间的数据复制。

**应用场景**

- APFS数据复制到OSS：

  - 将APFS的数据复制到对象存储OSS可用于数据备份。

  - 可将低频访问的数据转移存储至对象存储OSS中，优化存储成本。

- OSS数据复制到APFS：

  - 利用OSS支持多种方式导入数据的优势，可通过OSS将线下或其他系统中的数据导入APFS中，提升数据传输效率。

  - 可将企业早期积累在OSS中的大量数据，通过复制存储至APFS中，用于AI训练等场景。

**前提条件**

已完成组织的AliyunOSSPrivateCloudDrsSyncRoleRAM服务角色授权，具体操作，请参见<strong>《Apsara Uni-manager运营控制台 用户指南》</strong>手册中**配置中心>RAM服务角色**章节。

**操作步骤**

1. 登录APFS文件存储控制台。

2. 进入APFS文件系统列表页，单击目标文件的系统ID/名称或**操作**列的**详情**，进入文件系统的详情页，单击**数据流动**页签，进入数据流动任务页面。

   > **说明**
   >
   > 如果检测到当前组织未进行AliyunOSSPrivateCloudDrsSyncRoleRAM服务角色授权，进入数据流动任务页面时会自动弹出**云资源访问授权**对话框，可在对话框中选择目标组织完成授权。

3. 单击**创建数据流动任务**，在对话框中设置对应的参数。

   **参数项**

   **说明**

   - **APFS > OSS**：将APFS中的数据复制到OSS中。

   **任务项**

   - **OSS > APFS**：将OSS中的数据复制到APFS中。

   **数据源**

   **OSS作为数据源或目标路径的参数填写说明：**

   - 首先在单选框中下拉选择数据存放的Bucket。

   - 填写Bucket的具体文件路径。例如：/source_file/file01.txt

   **APFS作为数据源或目标路径的参数填写说明：**

   您需要填写的参数是目标文件或目录在默认挂载点下的相对路径。

   > **说明**
   >
   > APFS文件系统的默认挂载点为 /mnt/efs-xxx（例如：文件系统 efs-01d27e2c 的默认挂载点为 /mnt/efs-01d27e2c）

   填写规则：

   - 文件路径：

     - 如果目标文件的完整路径是 /mnt/efs-xxx/a.jpg，对应的需填写的路径参数应为 a.jpg 或/a.jpg。

   **目标路径**

   - 您只需提供从默认挂载点开始的路径部分，可以选择是否以斜杠 / 开头。

   - 目录路径：

     - 如果目标目录的完整路径是 /mnt/efs-xxx/bigdir/dir1，对应的参数应为 bigdir/dir1 或/bigdir/dir1。

     - 同样，您可以选择是否以斜杠 / 开头。

   示例：

   - 文件 /mnt/efs-xxx/images/photo.png 对应的参数为：images/photo.png 或/images/photo.png。

   - 目录 /mnt/efs-xxx/data/files 对应的参数为：data/files 或 /data/files。

   > **重要**
   >
   > - 请确保填写的路径是相对于默认挂载点的路径，而不是完整的绝对路径。
   >
   > - 如果路径中包含特殊字符（如空格、中文等），请正确转义或使用引号包裹路径。

   <table>
     <tr>
       <td>描述</td>
       <td>填写本次复制任务的相关描述。</td>
     </tr>
   </table>

   > **说明**
   >
   > 单个数据流动任务量数据不超过100TiB。

4. 单击**确定**提交数据复制任务。

5. 创建复制任务后，可在数据流动任务列表中查看任务状态、任务类型、任务结果、数据源、目标路径、描述、创建时间等信息。

## 4.1. 无售卖库存

本文介绍创建APFS文件系统因库存不足创建失败的解决方案。

**问题现象**

当创建或者扩容APFS文件系统时，可能会弹出异常提示窗口，提示信息如下：

![](assets/61114b7e5b37837a035e31f885155552.jpeg)

**解决方案**

方案一：缩小文件系统容量大小。

方案二：修改文件系统可用区。

方案三：删除多余文件系统，并联系驻场运维释放磁盘空间后，重试创建或扩容。
