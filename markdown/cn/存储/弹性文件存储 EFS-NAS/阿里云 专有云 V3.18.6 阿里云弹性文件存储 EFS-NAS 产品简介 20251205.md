# 1.产品详情

阿里云弹性文件存储 EFS-NAS（File Storage NAS） 是面向阿里云ECS实例、E-HPC、容器服务等计算节点的文件存储服务，是一种可共享访问、弹性扩展、高可靠以及高性能的分布式文件系统。

**产品类型**

EFS-NAS支持容量型和性能型两种实例类型，以满足不同的业务场景。

- 容量型实例

  - 基于SSD + HDD混合闪存服务器。

  - 提供大容量、成本优化的共享文件存储方案。

  - 适合档案管理、数据归档、视频监控回放等成本敏感场景。

- 性能型实例

  - 基于SSD全闪存服务器。

  - 提供高吞吐、低延迟的文件访问能力。

  - 适合高性能计算、媒体剪辑、数据库文件存储等性能敏感场景。

**核心功能**

- 文件系统挂载：支持多计算节点挂载文件系统。

- 弹性扩容：可对文件系统进行在线扩容，随业务增长动态调整容量。

- 挂载点：支持通过NFS/SMB协议共享生成挂载点。

- 配额管理：支持按照组织设置容量配额，实现资源的合理分配、成本控制和性能优化。

- 单一命名空间容量：最大支持 5 PiB容量，实现海量数据统一管理。

- 单集群最大规模：支持最多 2000 块磁盘，按需横向扩展。

- 3 台起步部署：满足小规模业务起步与平滑扩容的需求。

- 存储池灵活部署：支持文件存储集群底层的资源独占与灵活规划，降低初期设备投入数量。

**产品特性**

**协议支持与多协议互通**

- 支持NFS v3.0 / NFS v4.0协议。

- 支持SMB 2.1 / SMB 3.0协议。

- 支持多协议互通：同一目录/文件可通过NFS与SMB多种协议访问，满足跨操作系统与多种应用场景下的文件共享需求。

**数据安全与权限管理**

- 三副本保护：数据多副本冗余，确保存储高可用与数据安全。

- EC（Erasure Coding）纠删码保护：支持多种数据保护策略，包括2+1、4+2、8+3、4+2:1、8+2:1 模式，提升存储效率与可靠性。

- ACL 权限控制：支持 Windows ACL 和 Linux POSIX ACL 文件访问控制。

- 安全组控制：可基于客户端 IP 设置读写访问权限策略。

**审计与合规**

支持通过操作审计查询操作日志，满足企业审计、合规要求。

**产品优势**

- 性能与容量兼具：既能满足高性能低延迟需求，也可支撑海量低成本存储。

- 多协议互通与混访能力：同一数据源可被不同系统直接访问，提升多平台协作效率。

- 灵活弹性部署：在线扩容与资源池化管理，适配不同业务生命周期。

- 高可用与数据安全：三副本与EC纠删码结合，既保证高可靠性，又可优化存储利用率。

- 细粒度安全与审计：多级ACL权限、安全组策略与访问审计，满足企业安全、合规、政企与金融等行业监管要求。

<a id="section-2"></a>

# 2.产品价值

**高可用与数据可靠性**

通过多副本、EC纠删码数据冗余机制，确保在硬件故障时业务持续可用，并保障数据安全不丢失。

**共享一致性与高并发性能**

多计算实例可同时访问同一数据源，借助文件锁与事务机制保证强一致性；底层优化的I/O调度和分布式架构可在高并发访问下保持稳定的吞吐与低延迟。

**协议与生态互通**

支持标准的NFS v3、NFS v4.0、SMB 2.1 和 SMB 3.0 协议，兼容主流Linux与Windows系统，方便与现有业务系统无缝集成，降低迁移成本。

**多样化访问方式**

既可通过VPC在云内安全接入，也可通过专线、VPN等将本地IDC与云端打通，实现跨地域低延迟访问，满足混合云和多数据中心部署需求。

**安全合规**

提供细粒度权限控制、传输与存储加密、访问审计等功能，确保数据在访问全链路中的安全性，符合行业及监管要求。

**便捷运维与可视化管理**

管理控制台与API支持实时监控容量、性能、健康状态，并可自动告警与扩容，提升运维效率和可控性。

# 3.应用场景

在政企、金融和制造等行业，NAS（网络附加存储）因其文件共享便捷、扩展灵活及安全可控等特性，在多个业务场景中得到广泛应用，核心价值体现在集中管理、灵活扩容、快速检索、安全防护及跨地域协作等方面，能有效解决传统存储在容量、性能、可管理性和合规性上的不足。

**政企行业**

- 电子政务与业务档案管理：集中存储和管理部门公文、审批文件、影像材料，实现跨部门、跨地域的高效文件共享与协作。

- 公共安全与执法取证：存储高清视频监控、执法记录仪数据及审计日志，支持快速检索与长期归档，满足等级保护和监管要求。

- 司法机关电子检务：与业务系统联动，确保案卷、证据文件在多节点实时同步，提升案件办理效率与可追溯性。

**金融行业**

- 文件与影像归档管理：用于集中存储客户影像资料、合同扫描件、柜面单据等，便于快速调阅与灾备保存，满足合规要求。

- 业务报表与文件共享：为分支机构提供统一的文件访问平台，提高内部数据分发与协作效率。

- 双活/高可用业务支撑：依托NAS文件系统的高可用和复制能力，支撑电子影像系统、合规留痕系统的双中心运行，保障业务连续性。

**制造行业**

- 工业设计与研发数据管理：集中管理CAD图纸、工艺文件、测试视频等大文件，支持元数据标签和全文搜索，加快设计迭代。

- 生产过程与质量追溯：存储产线采集的工艺参数、设备日志、检测影像，实现按批次、时间等条件快速查询，支撑质量管理。

- 跨厂区协同与供应链共享：支持多工厂、供应商间安全共享生产资料和订单文件，实现实时协作与版本统一。

**可靠性及数据安全**

| 功能 | 说明 |
| --- | --- |
| 三副本 | 将每个数据块（Chunk）复制成三个相同的副本，并将这些副本按照一定的策略存放在集群中的不同节点上，这样可以确保即使某个节点发生故障，数据仍然可以从其他节点恢复。提供高数据可靠性，保护用户数据安全。 |
| EC（Erasure Coding）纠删码 | 纠删码技术将数据分为n个数据块和m个校验块，组成n+m的EC组，它们分别位于不同的服务器上，当丢失任意小于等于m个块时，都能通过EC算法恢复丢失的块。支持2+1、4+2、8+3、4+2:1、8+2:1的EC模式。 |
| NFS权限控制 | NFS共享支持基于客户端IP/网段配置读写、只读等权限及root压缩/全部压缩等规则。 |
| 用户/用户组 | SMB协议共享，支持按照用户/用户组进行权限管理，可以为不同用户/用户组分配不同的权限级别（如“读写”、“只读”、“完全控制”等），保障数据的访问安全。 |
| 审计日志 | 支持通过操作审计查询操作日志，满足企业审计、合规要求。 |
