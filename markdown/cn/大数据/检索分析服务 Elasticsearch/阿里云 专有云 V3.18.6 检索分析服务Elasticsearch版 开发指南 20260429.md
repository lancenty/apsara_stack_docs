# 1.使用Restful API交互

Elasticsearch采用Restful API，所有的操作都可通过HTTP API完成，例如增删改查、别名配置等。本文介绍Restful API的使用方法。

**参考文档**

- 单文档API：

  - Index API

  - Get API

  - Delete API

  - Update API

- 多文档API：

  - Multi Get API

  - Bulk API

  - Delete By Query API

  - Update By Query API

  - Reindex API

**使用REST Client交互**

客户端访问仅支持HTTP和TCP方式，建议您采用Elasticsearch官方提供的Java REST Client。

**使用Java API交互**

Elasticsearch为Java用户提供了内置客户端，包括TransportClient和Java REST Client。Elasticsearch 7.0中已经弃用TransportClient，在8.0中完全移除它。因此在实际开发中建议您使用Java REST Client。关于Java API的更多信息，请参见官方Java API以及Java API使用说明文档。

> **说明**
>
> Java客户端所使用的Elasticsearch版本必须与Elasticsearch集群版本一致，否则可能无法相互识别。

**REST API（HTTP）请求参数说明**

您可以使用RESTful API或者curl命令，通过9200端口与Elasticsearch进行通信。

> **说明**
>
> Elasticsearch官方提供了多种编程语言的客户端，例如Groovy、JavaScript、.NET、PHP、Perl、Python和Ruby以及很多由社区提供的客户端和插件，您可以在Community Contributed Clients中获取。

curl命令（HTTP）由以下几部分组成。

```bash
curl -X<VERB> '<PROTOCOL>://<HOST>:<PORT>/<PATH>?<QUERY_STRING>' -d '<BODY>'
```

**REST API（HTTP）请求示例**

通过以下命令，统计Elasticsearch集群中文档的数量。

```bash
curl -XGET 'http://localhost:9200/_count?pretty' -d '
{ 
  "query": { 
    "match_all": {} 
  }
}'
```

返回结果如下。

```json
{ 
    "count" : 0, 
    "_shards" : { 
        "total" : 5, 
        "successful" : 5, 
        "failed" : 0 
     }
}
```

使用 `curl -i` 显示HTTP请求头，例如 `curl -i -XGET 'localhost:9200/'` ，完整请求示例如下。

```bash
curl -i -XGET 'localhost:9200/_count?pretty' -d '
{ 
    "query": { 
        "match_all": {} 
    }
}'
```

简写请求示例如下。

```text
GET /_count
{ 
    "query": { 
        "match_all": {} 
    }
}
```

# 2.使用Python API交互

本文主要介绍如何使用Python访问阿里云Elasticsearch 7.10版本，包括客户端安装、连接配置、基本操作和端到端测试等。通过本手册，开发者可以快速掌握使用Python操作Elasticsearch的方法。

<a id="section-2-1"></a>

## 2.1. 准备工作

本文介绍使用Python访问阿里云Elasticsearch 7.10版本时的准备工作，包括环境要求、安装依赖、网络配置要求、客户端初始化及连接配置和认证配置。

**环境要求**

- Python版本：3.6或更高版本

- Elasticsearch版本：7.10.0（与阿里云Elasticsearch 7.10兼容）

- 依赖库： `elasticsearch>=7.10.0` 、 `urllib3`

**安装依赖**

在Python虚拟环境中安装所需的库：

```bash
pip install "elasticsearch>=7.10.0"
```

**网络配置要求**

不同网络配置方式下，需要满足以下要求：

- 公网访问：需在阿里云控制台开启实例公网地址，并将服务器公网IP加入访问白名单。

- VPC访问：如果应用也在阿里云，建议部署在同一VPC内，使用私网地址访问以获得更低延迟和更安全的连接。

- 连接池：在高并发场景下合理配置连接池大小，避免连接耗尽。

**客户端初始化及连接配置**

**基础连接配置**

```python
from elasticsearch import Elasticsearch

# 基础配置 - HTTP连接
es = Elasticsearch(
    hosts=['{ES集群地址}:9200'],  # 替换为你的ES集群地址
    http_auth=('username', 'password'),  # 替换为你的⽤户名和密码
    scheme="http",
    port=9200,
    timeout=30
)

# 测试连接
try:
    info = es.info()
    print("连接成功!", info.get('version'))
except Exception as e:
    print(f"连接失败: {e}")
```

**HTTPS连接配置**

对于生产环境，建议使用HTTPS加密连接。

```python
import ssl
from elasticsearch import Elasticsearch

# HTTPS连接配置
es = Elasticsearch(
    hosts=['{ES集群地址}:443'],
    http_auth=('username', 'password'),
    use_ssl=True,
    verify_certs=False,  # ⽣产环境建议设为True并提供正确的证书
    ssl_show_warn=False,
    timeout=30
)
```

**连接池配置**

针对高并发场景，可以配置连接池。

```python
from elasticsearch import Elasticsearch
from urllib3.poolmanager import PoolManager
import urllib3

# 配置连接池参数
es = Elasticsearch(
    hosts=['{ES集群地址}:9200'],
    http_auth=('username', 'password'),
    maxsize=50,  # 最⼤连接数
    timeout=30,
    connection_class=urllib3.PoolManager,
    # 其他连接参数
    retry_on_timeout=True,
    max_retries=10
)
```

**认证配置**

阿里云Elasticsearch服务要求通过Basic Authentication（基础认证）验证访问权限，认证凭据需使用创建实例时配置的用户名和密码。在客户端连接配置中，需通过  `http_auth`  参数显式指定认证信息，以确保请求合法性。

```python
from elasticsearch import Elasticsearch

# 使⽤⽤户名和密码进⾏认证
es = Elasticsearch(
    hosts=['{ES集群地址}:9200'],
    http_auth=('access_username', 'access_password'),
    scheme="http",
    port=9200,
    timeout=30
)
```

## 2.3. 完整操作示例

本文提供一个完整的操作示例，您可以用于进行基本的CRUD操作。

```python
from datetime import datetime
from elasticsearch import Elasticsearch, exceptions

class ElasticSearchClient:
    def __init__(self, hosts, username, password, index_name):
        # 初始化ES客户端
        self.es_client = Elasticsearch(
            hosts=hosts,
            http_auth=(username, password),
            scheme='http',
            timeout=30,
            maxsize=50
        )
        self.index_name = index_name
        
    def create_index(self):
        """创建索引"""
        mapping = {
            "mappings": {
                "properties": {
                    "title": {"type": "text"},
                    "content": {"type": "text"},
                    "timestamp": {"type": "date"}
                }
            }
        }
        
        try:
            if not self.es_client.indices.exists(index=self.index_name):
                response = self.es_client.indices.create(index=self.index_name, 
body=mapping)
                print(f"索引创建成功: {response}")
            else:
                print("索引已存在")
        except exceptions.RequestError as e:
            print(f"创建索引出错: {e}")

    def add_document(self, doc_id, doc_data):
        """添加⽂档"""
        try:
            response = self.es_client.index(
                index=self.index_name,
                doc_type='_doc',  # ES 7.x版本后固定为_doc
                id=doc_id,
                body=doc_data
            )
            print(f"⽂档添加成功: {response}")
            return response
        except exceptions.RequestError as e:
            print(f"添加⽂档出错: {e}")
            
    def get_document(self, doc_id):
        """获取⽂档"""
        try:
            response = self.es_client.get(
                index=self.index_name,
                doc_type='_doc',
                id=doc_id
            )
            return response['_source']
        except exceptions.NotFoundError:
            print("⽂档不存在")
            return None
            
    def search_documents(self, query):
        """搜索⽂档"""
        try:
            response = self.es_client.search(
                index=self.index_name,
                body=query
            )
            return response
        except exceptions.RequestError as e:
            print(f"搜索出错: {e}")
            return None
            
    def delete_document(self, doc_id):
        """删除⽂档"""
        try:
            response = self.es_client.delete(
                index=self.index_name,
                doc_type='_doc',
                id=doc_id
            )
            print(f"⽂档删除成功: {response}")
            return response
        except exceptions.NotFoundError:
            print("要删除的⽂档不存在")
            return None
            
    def close_connection(self):
        """关闭连接"""
        self.es_client.transport.close()

# 使⽤示例
if __name__ == "__main__":
    # 替换为实际的ES连接信息
    ES_HOSTS = ['{your-es-host}:9200']
    ES_USERNAME  {yourusername}'
    ES_PASSWORD = '{your-password}'
    INDEX_NAME = 'demo-index'
    
    # 创建客户端实例
    es_client = ElasticSearchClient(ES_HOSTS, ES_USERNAME, ES_PASSWORD, INDEX_NAME)
    
    # 测试所有功能
    try:
        # 创建索引
        es_client.create_index()
        
        # 添加⽂档
        sample_doc = {
            'title': 'Python Elasticsearch Demo',
            'content': '这是⼀个Python访问Elasticsearch的示例',
            'timestamp': datetime.now()
        }
        es_client.add_document('1', sample_doc)
        
        # 获取⽂档
        doc = es_client.get_document('1')
        print("检索到的⽂档:", doc)
        
        # 搜索⽂档
        query = {
            "query": {
                "match": {
                    "title": "Python"
                }
            }
        }
        results = es_client.search_documents(query)
        if results:
            print("搜索结果数量:", results['hits']['total']['value'])
            
        # 清理 - 删除⽂档（实际使⽤中可根据需要决定是否删除）
        # es_client.delete_document('1')
        
    finally:
        # 关闭连接
        es_client.close_connection()
```

## 2.5. 常见问题处理

本文介绍使用Python客户端执行搜索操作时的常见问题处理。

```python
from elasticsearch import Elasticsearch, exceptions

try:
    # 执⾏ES操作
    res = es.search(index="non-existent-index", body={"query": {"match_all": {}}})
except exceptions.NotFoundError:
    print("索引不存在")
except exceptions.ConnectionError:
    print("连接错误")
except Exception as e:
    print(f"其他错误: {e}")
```

本代码示例适用于以下阿里云 Elasticsearch开发场景，旨在帮助开发者通过Python客户端执行搜索操作时，实现对异常情况的精准捕获与响应：

- 索引存在性验证在开发或调试阶段，用于快速验证目标索引是否已创建。通过捕获  `NotFoundError`  异常，可判断索引是否缺失，从而触发后续的索引创建或数据初始化流程。

- 连接状态检测通过捕获  `ConnectionError`  异常，检测客户端与 Elasticsearch 集群之间的网络连通性、认证配置（如用户名/密码）或集群可用性，确保连接参数的正确性。

- 生产环境容错设计在生产系统中，通过异常处理机制避免因搜索操作失败导致程序崩溃，提供友好的错误提示或日志记录，便于运维人员快速定位问题。

- 通用错误调试捕获未预期的异常（如权限不足、查询语法错误），输出详细错误信息，辅助开发者进行问题诊断与代码优化。

### 2.6.1. 连接实例

本文介绍如何通过Java High Level REST Client连接Elasticsearch实例。

**maven依赖**

以Elasticsearch 7.10版本为例，maven依赖如下。

```text
<!--highLevelClient依赖-->
  <dependency>
      <groupId>org.elasticsearch.client</groupId>
      <artifactId>elasticsearch-rest-high-level-client</artifactId>
      <version>7.10.0</version>
  </dependency>
  <dependency>
      <groupId>org.elasticsearch.client</groupId>
      <artifactId>elasticsearch-rest-client</artifactId>
      <version>7.10.0</version>
  </dependency>
```

> **重要**
>
> - Java客户端所使用的elasticsearch-rest-high-level-client版本必须与Elasticsearch集群版本一致。
>
> - elasticsearch-rest-high-level-client没有5.5.3版本，如果您需要访问5.5.3版本的Elasticsearch集群，可以使用5.6.2版本的elasticsearch-rest-client。

**代码示例**

```text
@Bean("myRestHighLevelClient")
public RestHighLevelClient elasticsearchRestClient(){

   //集群地址。
   HttpHost httpHost = new HttpHost(hostName, 9200);

   //构建连接对象。
   RestClientBuilder builder = RestClient.builder(httpHost);

   //设置⽤户名和密码。通过在请求头中加入⽤户名和密码验证，防⽌第⼀次请求不带账号密码造成访问次数翻倍的
问题。
   String credentialsString = username + ":" + password;
   byte[] encodedBytes = Base64.getEncoder().encode(credentialsString.getBytes());
   Header[] headers = {new BasicHeader(AUTHORIZATION, "Basic " + new 
String(encodedBytes))};
   builder.setDefaultHeaders(headers);

    //连接延时配置。
   builder.setRequestConfigCallback(requestConfigBuild->{
     //建立连接超时时间设置。
     requestConfigBuild.setConnectTimeout(10*1000)
        .setSocketTimeout(15*1000)
        .setConnectionRequestTimeout(10*1000);
     return requestConfigBuild;
   });
   //连接数配置。
   builder.setHttpClientConfigCallback(httpClientBuilder->{
     httpClientBuilder.setMaxConnTotal(1000)
       .setMaxConnPerRoute(1000);
     return httpClientBuilder;
   });
   return new RestHighLevelClient(builder);
}
```

### 2.6.3. 写入数据

本文介绍如何通过Java API向Elasticsearch集群中写入数据，包括单条写入和Bulk写入（批量写入）。

**单条写入**

单条写入数据的情况下，指明文档id后，如果该文档id不存在，则创建文档。如果id存在，则更新对应文档。如果不指定文档id，则会由Elasticsearch随机生成。示例如下：

- 写入JSON格式的数据

  ```text
  //要写入的索引。
  IndexRequest request = new IndexRequest("index_name");
  //⽂档id。
  request.id("6");
  //⽂档的类型，7.x之前的版本中必须包含，且在5.5.3版本不能以下划线(_)开头。
  request.type("_doc");
  //写入的信息。
  String jsonString = "{" +
    "\"user\":\"kimchy\"," +
    "\"postDate\":\"2013-01-30\"," +
    "\"message\":\"trying out Elasticsearch\"" +
    "}";
  request.source(jsonString, XContentType.JSON);
  //6.3.2及之前的版本不需要RequestOptions.DEFAULT参数。
  IndexResponse response = restHighLevelClient.index(request, RequestOptions.DEFAULT);
  ```

- 写入map形式的数据

  ```text
  //要写入的索引。
  IndexRequest request = new IndexRequest("index_name");
  //⽂档id。
  request.id("6");
  //⽂档的类型，7.x之前的版本中必须包含，且在5.5.3版本不能以下划线(_)开头。
  request.type("_doc");
  //写入的信息。
  Map<String, String> map = new HashMap<String, String>();
  map.put("user","kimchy");
  map.put("postDate","2013-01-30");
  map.put("message","trying out Elasticsearch");
  request.source(map);
  //6.3.2及之前的版本不需要RequestOptions.DEFAULT参数。
  IndexResponse response = restHighLevelClient.index(request,RequestOptions.DEFAULT);
  ```

**Bulk写入**

Bulk写入时，可以选择指定或不指定id。如果不指定，则由Elasticsearch随机生成。示例如下：

- 7.x版本

  ```text
  BulkRequest request = new BulkRequest();
  request.add(new IndexRequest("index_name").id("299")
              .source(XContentType.JSON,"field", "foo"));
  request.add(new IndexRequest("index_name").id("399")
              .source(XContentType.JSON,"field", "bar"));
  request.add(new IndexRequest("index_name").id("499")
              .source(XContentType.JSON,"field", "baz"));
  BulkResponse response = restHighLevelClient.bulk(request,RequestOptions.DEFAULT);
  ```

- 6.x版本

  ```text
  BulkRequest request = new BulkRequest();
  request.add(new IndexRequest("index_name").id("1").type("_doc")
              .source(XContentType.JSON,"field", "foo"));
  request.add(new IndexRequest("index_name").id("2").type("_doc")
              .source(XContentType.JSON,"field", "bar"));
  request.add(new IndexRequest("index_name").id("3").type("_doc")
              .source(XContentType.JSON,"field", "baz"));
  //6.3.2及以下版本不需要RequestOptions.DEFAULT参数。
  BulkResponse response = restHighLevelClient.bulk(request, RequestOptions.DEFAULT);
  ```

- 5.5.3版本

  ```text
  //写入请求需要有type，且type的命名不能以下划线(_)开头。
  BulkRequest request = new BulkRequest();
  request.add(new IndexRequest("index_name").id("1").type("doc")
              .source(XContentType.JSON,"field", "foo"));
  request.add(new IndexRequest("index_name").id("2").type("doc")
              .source(XContentType.JSON,"field", "bar"));
  request.add(new IndexRequest("index_name").id("3").type("doc")
              .source(XContentType.JSON,"field", "baz"));
  BulkResponse response = restHighLevelClient.bulk(request);
  ```

### 2.6.4. 查询数据

本文介绍如何通过Java API查询Elasticsearch集群中的数据。

**match all search**

您可以在 `new SearchRequest()` 时传入索引名来指定查询某个索引的文档，也可以不指定具体索引，直接对所有索引进行文档查询。示例如下：

```text
SearchRequest searchRequest = new SearchRequest("index_name");
SearchSourceBuilder searchSourceBuilder = new SearchSourceBuilder();
searchSourceBuilder.query(QueryBuilders.matchAllQuery());
searchRequest.source(searchSourceBuilder);
//6.3.2及以下版本不需要RequestOptions.DEFAULT参数。
SearchResponse response = 
restHighLevelClient.search(searchRequest,RequestOptions.DEFAULT);
```

**term search**

sourceBuilder不仅允许设置query，可以通过from和size来对搜索结果进行设置。示例如下：

```text
SearchSourceBuilder sourceBuilder = new SearchSourceBuilder();
sourceBuilder.query(QueryBuilders.termQuery("user", "kimchy"));
//从结果的第⼏条⽂档开始取数据。
sourceBuilder.from(0);
//返回⼏条⽂档数据。
sourceBuilder.size(5);
sourceBuilder.timeout(new TimeValue(60, TimeUnit.SECONDS));
SearchRequest searchRequest = new SearchRequest();
searchRequest.indices("index_name");
searchRequest.source(sourceBuilder);
//6.3.2及以下版本不需要RequestOptions.DEFAULT参数。
SearchResponse response = 
restHighLevelClient.search(searchRequest,RequestOptions.DEFAULT);
```

**score search**

Elasticsearch的查询都会有score，通过score得分的高低对搜索结果进行排序和筛选。如果想要对score进行定制，可以通过 `sourceBuilder.sort()` 来实现，支持四种定制方式：Field、Score、GeoDistance和ScriptSortBuilder，分别是根据字段、得分、地理位置以及更丰富的自定义得分来对文档进行排序。示例如下：

```text
SearchSourceBuilder sourceBuilder = new SearchSourceBuilder();
//根据company字段降序排列。
sourceBuilder.sort(new FieldSortBuilder("company.keyword").order(SortOrder.DESC));
sourceBuilder.size(30);
SearchRequest request = new SearchRequest("index_name");
request.source(sourceBuilder);
//6.3.2及以下版本不需要RequestOptions.DEFAULT参数。
SearchResponse search = restHighLevelClient.search(request,RequestOptions.DEFAULT);
```

**聚合查询（aggreation search）**

示例如下：

```text
SearchSourceBuilder sourceBuilder = new SearchSourceBuilder();
//根据company⼦字段进⾏名为"by_company"的聚合查询。company不是keyword类型，其⼦字段company.keyword是keyword类型。
TermsAggregationBuilder aggregation = AggregationBuilders.terms("by_company")
  .field("company.keyword");
sourceBuilder.aggregation(aggregation);
SearchRequest request = new SearchRequest("index_name");
request.source(sourceBuilder);
SearchResponse search = restHighLevelClient.search(request,RequestOptions.DEFAULT);
```

> 聚合查询时只能对Keyword类型字段进行聚合，对其他类型字段聚合时会报错
>
> **重要**
>
> illegal_argument_exception。

### 3.2.2. 获取AccessKey

AccessKey支持RAM和STS两种授权模式，在发起调用时选择使用其中一种AccessKey即可。本文将为您介绍如何获取通过RAM授权的AccessKey。

**背景信息**

AccessKey通过使用AccessKey ID和AccessKey Secret对称加密，实现验证某个请求发送者的身份的功能。其中AccessKey ID用于标示用户，AccessKey Secret是用户用于加密签名的字符串。

AccessKey的两种授权模式如下：

- 通过RAM授权给第三方请求者的AccessKey ID和AccessKey Secret。

- 通过STS授权给第三方请求者的AccessKey ID、AccessKey Secret和Security Token。获取方式请参见获取STS AccessKey。

Apsara Uni-manager运营控制台提供了个人AccessKey和组织AccessKey（只有运营管理员和一级组织管理员可以获取组织AccessKey），推荐使用个人账号AccessKey调用Apsara Uni-manager运营控制台及云产品相关接口。如果使用个人账号AccessKey，需要在Header中添加以下限制性参数，否则可能提示权限不足：

## 4.1. STS概要

<a id="section-4-1-1"></a>

### 4.1.1. 什么是STS

阿里云STS（Security Token Service）是阿里云提供的一种临时访问权限管理服务。RAM提供RAM用户和RAM角色两种身份。其中，RAM角色不具备永久身份凭证，而只能通过STS获取可以自定义时效和访问权限的临时身份凭证，即安全令牌（STS Token）。

**使用RAM用户扮演角色时获取STS Token**

有权限的RAM用户可以使用其访问密钥调用AssumeRole接口，以获取某个RAM角色的STS Token，从而使用STS Token访问阿里云资源。

**产品优势**

- 使用STS Token，减少长期访问密钥（Accesskey）泄露的风险。

- STS Token具有时效性，可以自定义有效期，到期后将自动失效，无需定期轮换。

- 可以为STS Token绑定自定义权限策略，提供更加灵活和精细的云资源授权。

<a id="section-4-1-2"></a>

### 4.1.2. AssumeRole

RAM用户调用AssumeRole接口获取一个扮演RAM角色的临时身份凭证STS Token。该接口中RAM用户扮演的是可信实体为阿里云账号类型的RAM角色。

**请求参数**

| 名称 | 类型 | 是否必选 | 示例值 | 描述 |
| --- | --- | --- | --- | --- |
| Action | String | 是 | AssumeRole | 要执行的操作。取值：AssumeRole |
| RoleArn | String | 是 | acs:ram::123456 789012\*\*\*\*:role/adminrole | 要扮演的RAM角色ARN。该角色是可信实体为阿里云账号类型的RAM角色。 |
| RoleSessionNa me | String | 是 | alice | 角色会话名称。该参数为用户自定义参数。通常设置为调用该API的用户身份，例如：用户名。在操作审计日志中，即使是同一个RAM角色执行的操作，也可以根据不同的<strong>RoleSessionName</strong>来区分实际操作者，以实现用户级别的访问审计。长度为2~64个字符，可包含英文字母、数字、半角句号（.）、at（@）、短划线（-）和下划线（_）。 |
| Policy | String | 否 | {"Statement": \[{"Action": \["\*"\],"Effect": "Allow","Resourc e": \["\*"\]}\],"Version":" 1"} | 为STS Token额外添加的一个权限策略，进一步限制STS Token的权限。具体如下：长度为1~1024个字符。 |

| Credentials | 无 | 无 | 访问凭证。 |
| AccessKeyId | String | STS.L4aBSCSJVMuK g5U1\*\*\*\* | 访问密钥ID。 |
| AccessKeySecret | String | wyLTSmsyPGP1ohv vw8xYgB29dlGI8KM iH2pK\*\*\*\* | 访问密钥。 |

**调用API获取STS AccessKey三元组**

以下代码示例为通过调用 `Sts::AssumeRole::2015-04-01` 获取STS AccessKey三元组信息。

```xml
package com.aliyuns.test;

import com.alibaba.fastjson.JSONObject;
import com.aliyuncs.CommonRequest;
import com.aliyuncs.CommonResponse;
import com.aliyuncs.DefaultAcsClient;
import com.aliyuncs.IAcsClient;
import com.aliyuncs.exceptions.ClientException;
import com.aliyuncs.exceptions.ServerException;
import com.aliyuncs.http.FormatType;
import com.aliyuncs.http.HttpClientConfig;
import com.aliyuncs.http.MethodType;
import com.aliyuncs.http.ProtocolType;
import com.aliyuncs.profile.DefaultProfile;
import org.apache.commons.lang3.StringUtils;

public class STSAccessKeyDemo {
    public static void main(String[] args) {
        // 创建DefaultAcsClient实例并初始化。
        DefaultProfile profile = DefaultProfile.getProfile("<yourRegionID>", "
<yourAccessKeyID>", "<yourAccessKeySecret>");
        HttpClientConfig clientConfig = HttpClientConfig.getDefault();
        clientConfig.setIgnoreSSLCerts(true);
        clientConfig.setProtocolType(ProtocolType.HTTPS);
        profile.setHttpClientConfig(clientConfig);
        IAcsClient client = new DefaultAcsClient(profile);
        CommonRequest request = new CommonRequest();
        // "sts.aliyuns.com"要替换为实际的STS Endpoint，⼀般格式为sts-
vpc.${global:region}.${global:internet-domain}
        request.setSysDomain("sts.aliyuns.com");
        request.setSysProduct("Sts");
        request.setSysAction("AssumeRole");
        request.setSysVersion("2015-04-01");
        request.setSysMethod(MethodType.POST);
        request.setHttpContentType(FormatType.FORM);
        // 业务参数，设置本次调⽤Session的别名，"<yourRoleSessionName>"请替换为实际值
        request.putQueryParameter("RoleSessionName", "<yourRoleSessionName>");
        // 扮演的Role⾓⾊ARN，"<yourRoleArn>"请替换为上⼀步获取到的实际Ram Role ARN
        request.putQueryParameter("RoleArn", "<yourRoleArn>");
        try {
            CommonResponse response = client.getCommonResponse(request);
            String assumeRole = response.getData();
            if (StringUtils.isEmpty(assumeRole)) return;
            JSONObject assumeRoleJson = JSONObject.parseObject(assumeRole);
            JSONObject credentials = assumeRoleJson.getJSONObject("Credentials");
            // 获取到STS三元组
            String stsAK = credentials.getString("AccessKeyId");
            String stsSK = credentials.getString("AccessKeySecret");
            String stsToken = credentials.getString("SecurityToken");
            System.out.println("stsAk: " + stsAK +"\nstsSk: " + stsSK + "\nstsToken: " 
+ stsToken);
        } catch (ServerException e) {
            System.out.println(e.getErrCode());
            System.out.println(e.getErrMsg());
        } catch (ClientException e) {
            System.out.println(e.getErrCode());
            System.out.println(e.getErrMsg());
        }
    }
```
