# 1.登录飞天基础运维平台

本文介绍如何登录飞天基础运维平台。

**前提条件**

- 已从部署人员或管理员处获取Apsara Uni-manager运维控制台的访问地址、用户名和密码。

  Apsara Uni-manager运维控制台访问地址格式为*region-id*.ops.console.*intranet-domain-id*。

- 推荐使用Chrome浏览器。

**操作步骤**

1. 打开浏览器。

2. 在地址栏中，输入Apsara Uni-manager运维控制台的访问地址，按回车键。

   ![](zh-waf-operations-guide-v3.18.6-20250529.assets/8687be861b518abf130a8b39086e180e.jpeg)

   > **说明**
   >
   > 您可以单击右上角的当前语言切换其它语言。当前支持简体中文、英文、繁体中文三种语言切换。

3. 输入正确的用户名及密码。

   > **说明**
   >
   > - 登录Apsara Uni-manager运维控制台的用户名和密码请从部署人员或管理员处获取。
   >
   > - 若连续输入密码错误三次，系统将启动图片验证码登录功能；若连续输入错误五次，账户将被锁定，请联系管理员进行激活。

   首次登录Apsara Uni-manager运维控制台时，需要修改登录用户名的密码，请按照提示完成密码修改。

   为提高安全性，密码必须满足以下要求：

   - 必须包含英文大小写字母。

   - 必须包含阿拉伯数字（0~9）。

   - 必须包含特殊符号，包括感叹号（!）、at（@）、井号（#）、美元符号（$）、百分号（%）等。

   - 密码长度为10~20个字符。

4. 单击**账号登录**。

5. 在Apsara Uni-manager运维控制台的顶部菜单栏，选择**安全管理 > 网络安全 > Web应用防火墙**。

# 2.检查服务状态

<a id="section-2-1"></a>

## 2.1. 基础巡检

Web应用防火墙（以下简称WAF）基础巡检内容为产品状态巡查。

**操作步骤**

1. 登录飞天基础运维平台。

2. 单击**运维 > 集群运维**。

3. 在**集群**搜索框输入**SemaWafCluster**。

4. 单击集群名，进入**集群详情**页面。

5. 在**服务管理**页签的**服务**搜索框输入**yundun-semawaf**，查看服务状态是否正常。

<a id="section-2-2"></a>

## 2.2. 高级巡检

WAF的高级巡检内容主要为系统状态和服务状态的检查。

**操作步骤**

1. 登录WAF的两台物理机。

   <ol type="i">

   <li>

   选择**运维 > 集群运维**。

   </li>

   <li>

   在**集群**搜索框输入**SemaWafCluster**，单击集群名进入**集群详情**页面。

   </li>

   <li>

   在**服务管理**页签的**服务**搜索框输入**yundun-semawaf**，单击**详情**按钮，进入**服务详情**页面。

   </li>

   <li>

   在**服务角色**区域选择**YundunSemawafApp#**。

   </li>

   <li>

   查看机器信息，单击**Terminal**登录WAF两台物理机。

   </li>

   </ol>

2. 系统检查。

   <ol type="i">

   <li>

   检查系统日志。

   执行 `dmesg -T |tail -30` ，查看是否有异常日志。

   </li>

   <li>

   检查系统负载。

   - 执行 `free -h` ，查看内存占用是否正常。

   - 执行 `df -h` ，查看磁盘占用是否正常。

   - 执行 `uptime` ，查看系统 load average 是否正常。

   - 执行 `top` ，查看系统 CPU 占用是否正常。

   </li>

   </ol>

3. 服务检查。

   > **说明**
   >
   > 以下检查基于安装目录，默认情况下为/home/safeline。

   <ol type="i">

   <li>

   执行 `cd /home/safeline` 进入安装目录。

   </li>

   <li>

   检查minion服务。

   <ol type="a">

   <li>

   执行 `systemctl status minion`  ，查看运行时间与运行状态。

   </li>

   <li>

   执行 `tail -100 logs/minion/minion.log` ，查看是否有异常日志。

   </li>

   </ol>

   </li>

   <li>

   检查mgt-api服务。

   <ol type="a">

   <li>

   执行 `docker logs --tail 50 mgt-api` ，查看是否有异常日志。

   </li>

   <li>

   执行 `docker exec -it mgt-api supervisorctl status` ，查看服务是否正常运行，**uptime**是否正常。

   </li>

   </ol>

   <li>

   </li>

   </li>
