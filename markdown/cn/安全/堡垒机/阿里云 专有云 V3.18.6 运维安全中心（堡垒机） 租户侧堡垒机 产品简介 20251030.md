# 1.产品详情

阿里云盾堡垒机是阿里在多年运维安全管理的理论和实践经验积累的基础上，结合各类法律法规（如等级保护等）对运维审计的要求，采用B/S架构，集“身份认证（Authentication）、账户管理（Account）、控制权限（Authorization）、日志审计（Audit）”于一体，支持多种字符终端协议、文件传输协议、图形终端协议、远程应用协议的安全监控与历史查询，具备全方位运维风险控制能力的统一安全管理与审计产品。

**用户分权**

支持多种用户角色：超级管理员、部门管理员、运维管理员、审计管理员、运维员、审计员、系统管理员，每种用户角色的权限都不同，为用设立不同的角色提供了选择，并且满足合规对三权分立的要求。

**集中授权**

通过集中授权，帮助客户梳理用户与主机直接的关系，并且提供一对一、一对多、多对一、多对多的灵活授权模式。

**单点登录**

云盾堡垒机支持托管主机的账户和密码，运维人员直接点击<登录>即可成功自动登录到目标主机中进行运维操作，无需输入主机的账户和密码。

**统一审计**

云盾堡垒机对所有的操作进行详细记录，并提供综合查询功能；审计日志可以在线播放，操作日志支持自动备份。

**自动改密**

对网管人员来说，需要定期手动修改网络设备的账户密码信息。通过云盾堡垒机的改密计划功能，实现定期自动化的轮转资产账户的密码。

**命令控制**

云盾堡垒机提供了集中的命令控制策略功能，实现基于不同的主机、不同的用户设置不同的命令控制策略，策略提供命令阻断、命令黑名单、命令白名单三种动作条件。

**工单流程**

操作人员向管理员申请需要访问的设备，申请时可以选择：设备IP、设备账户、运维有效期、备注事由等，并且运维工单以邮件方式通知管理员。

管理员对运维工单进行审核之后以邮件方式通知给运维人员；如果允许，则运维人员才可访问；否则就无法访问。

**系统自审**

云盾堡垒机作为审计类产品，不光要实现对操作行为进行审计，还要做到对系统自身变化信息进行审计，并且形成系统报表分析。

# 3.产品价值

**让操作过程变得透明**

每天都有不同的人在操作和维护主机，管理员无法得知运维人员在资产中具体做了什么操作、是否有违规和误操作，更加无法实时监控外部人员的操作过程，一旦发生运维安全事故，无法确定责任人。

堡垒机具备全面的运维审计功能，支持运维过程中的实时监控，运维会话结束后，支持查看录像回放，实现运维操作全审计。

**降低资产账户管理成本**

主机资源越多，系统账户也越多，而且面临着一个主机有很多的账户；可能一个账户被不同的人使用、一个人使用不同的账户、不同的人交叉使用不同的账户等等。对管理层来说无法集中梳理账户与自然人员的关系，甚至担心临时账户的存在造成数据的泄露。

堡垒机支持托管资产及资产账户，通过授权规则梳理资产运维权限，降低管理成本，同时支持设置多种访问控制策略，避免越权访问。

**提高运维工作效率**

随着主机账户不断增加，密码的管理和修改也成为管理员的一个难题，既要保证密码的复杂度，又要确保每隔一段时间进行修改，手工修改只会增加工作量。主机类型多了，造成了登录繁琐；Linux/Unix需要使用字符客户端工具，Windows需要使用远程桌面连接工具，Web系统需要使用浏览器，数据库需要使用数据库客户端工具等等。

堡垒机支持多种运维方式，可以通过Web网页直接访问资产，也可以通过单点登录器直接调用本地客户端访问，同时堡垒机支持运维人员对多台资产批量运维，大大提高运维效率。

**有效管控运维高危操作**

操作人员可能会因为无意操作造成数据丢失、业务故障等，黑客也可能远程进入主机之后进行有意的数据窃取、数据篡改等；如果想要做精确控制，需要管理人员在很多主机中做各种精细化的策略才有可能控制有意或无意的高危操作。

堡垒机支持设置命令控制策略，对运维过程中可能出现的高危命令执行等敏感操作可以进行实时阻断，根据业务需求灵活调整管控策略，有效管控高位敏感操作。

**满足合规要求**

目前国内、国际的很多标准、法案法规都要求相关组织单位建设安全管理的审计系统，并确保审计信息是安全、完整、可查及唯一的：

- 信息安全等级保护要求用户身份识别、权限隔离、数据审计、日志记录、审计报表等。

- ISO27001标准要求记录用户访问、意外和信息安全事件的日志，以便为安全事件调查取证等。

- SOX法案要求组织设计和执行了适当的控制，以确保财务报表数据的可靠、可信等。

- 企业内控规范要求企业严格执行规范要求，以加强和规范内部控制、提高风险防范能力等。

# 4.应用场景

**资产集中管控，解决资产分散难管理问题**

云盾堡垒机支持管理主机、数据库、应用等多种类型资产运维，支持资产自动发现，可托管资产账户，通过访问权限划分用户访问资产的权限，防止越权访问。

**运维方式丰富多样，适用自动化运维等复杂场景**

云盾堡垒机适应不同的运维人员的运维习惯，兼容多种客户端工具（如Xshell、SecureCRT、MobaXTerm、mstsc、VNC Viewer、Putty、winscp、flashFXP、SecureFX、OpenSSH等）和更加灵活的运维方式：

- Web登录运维，适用于习惯于使用网页登录主机的运维人员。

- 客户端登录运维，适用于习惯使用本地客户端工具登录堡垒机再登录目标主机的运维人员。

同时支持批量运维任务，可同时针对多台主机进行脚本及命令执行，提高运维效率。

**运维全面管控审计，助力满足内审及等保合规需求**

云盾堡垒机支持用户身份鉴别、访问权限划分、运维操作审计等功能，助力企业内审及等保合规建设。
