# 1.阿里云盾堡垒机运维手册

## 1.1. 运维员的Web运维方式

管理员给运维员授权了主机之后，运维员就能通过运维审计系统的Web页面登录主机进行运维。仅限于Windows终端的运维人员使用。

<a id="section-1-1-1"></a>

### 1.1.1. 登录系统

本文介绍如何登录运维审计系统。

1. 使用浏览器登录运维审计系统，输入用户名、密码和验证码。

2. 单击**登录**后进入系统。首次登录需要修改密码。

<a id="section-1-1-2"></a>

### 1.1.2. 安装单点登录器

本文介绍如何安装单点登录器。

1. 在页面右上角中，进入工具下载页面。

   ![](zh-bastionhost-tenant-side-operations-guide-v3.18.6-20251030.assets/b52d954fb6d9d04e87e07bee63a69a9a.png)

2. 下载并默认安装单点登录器。

   ![](zh-bastionhost-tenant-side-operations-guide-v3.18.6-20251030.assets/0952baa0c26230361b58d8244246015c.png)

   > **说明**
   >
   > 单点登录器是用于Web方式调用本地运维客户端工具时，需安装的登录工具。不要被杀毒软件拦截！

<a id="section-1-1-3"></a>

### 1.1.3. 指定运维工具

本文以Xshell工具为例介绍如何指定运维工具。

1. 单击**SSH**，进入配置页面，选择客户端程序、终端类型、编码格式。

   ![](zh-bastionhost-tenant-side-operations-guide-v3.18.6-20251030.assets/b5da8baa43362dd7f3a0bb1913c408e0.png)

2. 单击**保存**后弹出对话框，指定本地的应用程序。

   单击登录配置示意图：

   ![](zh-bastionhost-tenant-side-operations-guide-v3.18.6-20251030.assets/5041463fdf69c90d51238f2c539b1aea.png)

3. 单击**确定**后，提示配置成功。

   配置成功提示示意图：

   ![](zh-bastionhost-tenant-side-operations-guide-v3.18.6-20251030.assets/043da2ff4353346bf1c184d8fbba5d71.png)

4. 单击**确定**后即可生效。

   配置完成之后，关闭页面即可。

## 1.2. 运维员C/S方式运维

运维员通过本地的客户端工具登录运维审计系统，再访问目标主机。

<a id="section-1-2-1"></a>

### 1.2.1. 准备工作

本文介绍C/S运维前的准备工作。

**本地安装好支持SSH协议的运维工具**

例如putty、SecureCRT、Xshell等。

**本地安装好支持RDP协议的运维工具**

例如Windows系统自动的远程桌面连接工具。

**本地安装好支持SFTP协议的运维工具**

例如winSCP、XFTP工具。

**本地安装好支持FTP协议的运维工具**

例如XFTP工具。

**确保终端与运维审计系统的端口可达**

运维审计系统的默认端口是：

- 60022用于访问SSH、telnet、SFTP协议的主机。

- 63389用于访问RDP协议的主机。

- 60021用于访问FTP协议的主机。

<a id="section-1-2-2"></a>

### 1.2.2. 主机运维

<a id="section-1-2-2-1"></a>

#### 1.2.2.1. SSH、telnet、rlogin协议的主机运维

本文以Xshell为例介绍SSH、telnet、rlogin协议的主机运维。

1. 打开Xshell工具，在登录窗口中输入运维审计系统的IP和端口号（60022）。

   ![](zh-bastionhost-tenant-side-operations-guide-v3.18.6-20251030.assets/903bdd330e9255d43b4c44a48d91ccb1.png)

2. 单击**Connect**，进入登录窗口，输入运维审计系统的用户名和密码。

   ![](zh-bastionhost-tenant-side-operations-guide-v3.18.6-20251030.assets/5dc1828ebfbf969e4bb19a288b0b8142.jpeg)

3. 单击**OK**，进入资产管理界面，并通过“上、下、回车键”查找主机。

   ![](zh-bastionhost-tenant-side-operations-guide-v3.18.6-20251030.assets/09714b4fb651bc3fb352d091aefaafed.png)

4. 回车后，弹出主机账户输入框，输入主机账户。

   ![](zh-bastionhost-tenant-side-operations-guide-v3.18.6-20251030.assets/9cb430848ce5a74738f0ed4a4fce1fdf.jpeg)

5. 回车后进入输入主机登录界面，输入主机的密码。

   ![](zh-bastionhost-tenant-side-operations-guide-v3.18.6-20251030.assets/cfcfb8f4993f4c55c0369120cd7249cd.jpeg)

6. 回车之后即可进入主机运维操作界面。

   ![](zh-bastionhost-tenant-side-operations-guide-v3.18.6-20251030.assets/3e9381f250bf47f1838f7620441a86bb.jpeg)

<a id="section-1-2-2-2"></a>

#### 1.2.2.2. RDP协议的主机运维

本文以mstsc远程桌面连接工具为例介绍RDP协议的主机运维。

![](zh-bastionhost-tenant-side-operations-guide-v3.18.6-20251030.assets/b70206031ade4a94c9d059062a23f259.png)

1. 打开windows的**开始**，在运行输入框中输入mstsc，回车后，弹出**远程桌面连接**对话框，输入 运维审计系统的`IP 63389` 。

   ![](zh-bastionhost-tenant-side-operations-guide-v3.18.6-20251030.assets/dff629d4eda695df0bbbcbb75febd52b.jpeg)

2. 单击**连接**后，弹出<strong>是否信任此远程连接？</strong>对话框。

   ![](zh-bastionhost-tenant-side-operations-guide-v3.18.6-20251030.assets/55719139016506ff98b2901ed16ea680.jpeg)

3. 单击**连接**后，弹出<strong>无法验证次远程计算机的身份。是否仍要连接？</strong>对话框。

   ![](zh-bastionhost-tenant-side-operations-guide-v3.18.6-20251030.assets/4d7054d417065172ba362af35c20287a.jpeg)

4. 单击**是**，弹出运维审计系统登录对话框，输入运维审计系统的用户名和密码。

   ![](zh-bastionhost-tenant-side-operations-guide-v3.18.6-20251030.assets/7b20ccf4c169c9ec7bfad6093a91613d.png)

5. 单击**登录**后进入资产管理界面，用鼠标选择授权的资产，或者通过“搜索框”搜索主机信息。

   ![](zh-bastionhost-tenant-side-operations-guide-v3.18.6-20251030.assets/56b046a3547806253ffa3162768335b0.png)

6. 双击主机后，进入目标主机的登录界面，输入主机的账户和密码。

   ![](zh-bastionhost-tenant-side-operations-guide-v3.18.6-20251030.assets/00725b0148e133d3238fe789f0a940e6.jpeg)

7. 回车之后即可进入目标主机进行运维操作。

<a id="section-1-2-2-3"></a>

#### 1.2.2.3. SFTP协议的主机运维

本文以winSCP为例介绍SFTP协议的主机运维。

1. 打开winSCP工具，在登录窗口中输入运维审计系统的IP、端口号（60022）、用户名和密码。

   ![](zh-bastionhost-tenant-side-operations-guide-v3.18.6-20251030.assets/97719bc62da50eec06de0e06d9def948.jpeg)

2. 单击**登录**后，可以看到右侧的主机列表。

   ![](zh-bastionhost-tenant-side-operations-guide-v3.18.6-20251030.assets/08f85b0cd46781294d67200228a1f3aa.jpeg)

3. 双击之后，进入主机的目录，然后可以进行文件传输操作。

   ![](zh-bastionhost-tenant-side-operations-guide-v3.18.6-20251030.assets/5a1a0861c89a4c04adb466dd8f9d30a3.jpeg)

<a id="section-1-2-2-4"></a>

#### 1.2.2.4. FTP协议的主机运维

本文以XFTP工具为例介绍FTP协议的主机运维。

1. 运维员通过浏览器进入堡垒机的Web页面，在页面右上角，单击用户名，可以看到**查看个人信息**。

   ![](zh-bastionhost-tenant-side-operations-guide-v3.18.6-20251030.assets/5271697bf31db299232f181fed58610f.jpeg)

2. 在**个人信息**页面的**CS登录口令**页签，设置一个CS登录口令，此密码用于FTP主机C/S方式登录运维审计系统。

   ![](zh-bastionhost-tenant-side-operations-guide-v3.18.6-20251030.assets/e0034f10175d8f30e0b078b8b69b954c.jpeg)

3. 打开XFTP工具，在登录窗口中输入运维审计系统的IP、端口号（60021）、用户名、CS登录口令和FTP协议。

   ![](zh-bastionhost-tenant-side-operations-guide-v3.18.6-20251030.assets/931c26580803a5c2d6608a2ca3426572.jpeg)

4. 单击**连接**后，可以看到右侧的主机列表。

   ![](zh-bastionhost-tenant-side-operations-guide-v3.18.6-20251030.assets/806f5f8f8b5ace41f7822eb3876a19c7.jpeg)

5. 双击之后，进入主机的目录，然后可以进行文件传输操作。

   ![](zh-bastionhost-tenant-side-operations-guide-v3.18.6-20251030.assets/1dedc061da88fff01ca50e3f4c9c89c9.jpeg)

## 1.3. 苹果系统的电脑登录运维

运维人员通过苹果系统的App（客户端工具）登录运维审计系统，再访问目标主机。

> **说明**
>
> 由于单点登录器仅适用于Windows系统，因此苹果系统当前不支持Web运维方式登录堡垒机

**本地安装好支持SSH协议的App**

例如命令行终端、SecureCRT、Xshell等App。

**本地安装好支持RDP协议的App**

例如远程桌面连接App。

**确保苹果系统与运维审计系统的端口可达**

- 60022：用于访问SSH协议的主机。

- 63389：用于访问RDP协议的主机。

**确保运维审计系统与目标主机的运维端口可达**

SSH及端口、RDP及端口。
