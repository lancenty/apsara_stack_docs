# 1.API简介

欢迎您选择裸机管理BMS（BareMetal Mangement Service），如果您熟悉网络服务协议和一种以上编程语言，推荐您调用API管理您的云上资源和开发自己的应用程序。

**使用说明**

BMS API支持HTTP或HTTPS网络请求协议，仅允许POST方法。您可以通过SDK方式调用BMS API：

- 参考裸机管理BMS提供的开发指南（本指南），通过SDK调用BMS相关的API。

- 不同调用方式的示例操作，请参见调用方式。

**资源术语**

| 中文 | 常见参数 | 说明 |
| --- | --- | --- |
| 地域 | Region | 阿里云建设的数据中心。资源创建成功后无法更换地域。 |
| 可用区 | Zone | 同一地域内，电力和网络互相独立的物理数据中心。一个地域下可以有多个可用区。同一地域内可用区之间内网互通并且故障隔离。 |
| 裸机实例 | InstanceId/ID | 提供用户进行物理机的申请、释放、删除、重新申请的资产运营管理能力，提供用户对存量的实例进行开关机、重启等远程运维操作的能力。 |
| 镜像 | Image | 一般包含了操作系统和应用软件。用于维护裸机装机时使用的镜像元数据。 |
| 应用分组 | ApplicationGrou p | 区分该实例资产的分组。<br>• <strong>裸机实例</strong>：提供用户进行物理机的申请、释放、删除、重新申请的资产运营管理能力，提供用户对存量的实例进行开关机、重启等远程运维操作的能力。<br>• <strong>带内托管实例</strong>：针对用户侧存量服务器的带内托管需求，提供新增带内托管实例、查询、信息展示、单机监控、远程运营操作的功能。<br>• <strong>带外托管实例</strong>：针对用户对带外托管的需求，提供新增带外托管实例、查询、信息展示、单机监控、登录带外控制台、远程运营操作的功能 |

# 3.调用方式

通过HTTP调用接口。推荐使用阿里云官方aliyunsdkcore封装接口请求，以下为使用aliyunsdkcore封装接口请求的用例。

<a id="section-3-1"></a>

## 3.1. Python-SDK

SDK版本依赖与参数配置要求：

1. aliyun-python-sdk-core>=2.13.8。

2. AcsClient设置verify=False。

3. CommonRequest设置protocol_type为"https"。

以"/v1/ascm/instance/listInstance"(ListInstance)为例：

```python
# coding=utf-8

from aliyunsdkcore.client import AcsClient
from aliyunsdkcore.request import CommonRequest

RegionId = "xxxxxx"

bmsDomain := "{domain}"
usrAccessSecret = "xxxxxx" # ⽤户ak
usrAccessKey = "xxxxxx" # ⽤户ak

client = AcsClient(usrAccessKey, usrAccessSecret, RegionId, verify=False)

r = CommonRequest()

# https⽅式访问 需要设置protocol_type为"https"
# r.set_protocol_type("https")

r.set_domain(bmsDomain)
r.set_version("2022-05-30")
r.set_action_name("ListInstance")
r.set_product("bms")

# 接⼝url
r.set_uri_pattern("/v1/ascm/instance/listInstance")

r.add_body_params("PageNumber", 1)  # 必传
r.add_body_params("PageSize", 10)  # 必传
r.add_body_params("QueryKey", "")  # 选传
r.add_body_params("QueryValue", "")  # 选传
r.add_body_params("SortType", "asc")  # 选传 asc或desc
r.add_body_params("SortField", "")  # 选传 不传默认为创建时间降序
r.add_body_params("ApplicationGroup", "instance")
r.add_body_params("OwnerType", "")  # 选传
r.add_body_params("State", "")  # 选传 不传默认为创建时间降序

r.set_method("POST")
resp = client.do_action(r)
```
