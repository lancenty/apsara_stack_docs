# 1.产品详情

裸金属算力平台（BareMetal Computing Platform，BMCP）整体定位为AI Infra IAAS平台，专注于算力资源的统一管理和供给。它是一款大规模高性能的算力管理平台产品，基于飞天企业版，提供裸金属、容器等多样化的高性能算力集群服务。

- 可面向自然语言处理、通用大模型等大规模分布式的AI研发场景，提供高扩展性、高性能和高性价比的高性能基础设施服务。

- 提供裸金属算力集群、容器算力集群和AI平台服务等多种算力类型，满足不同用户对于不同算力类型的要求。

- BMCP支持对客户已有高性能算力集群的纳管，通过云化资源管理，帮助用户实现“智算上云”。

<a id="section-2"></a>

# 2.产品优势

BMCP平台的主要特点和优势包括：

1. 高性能: 裸金属服务器提供不受虚拟化技术影响的原生硬件性能，使得计算密集型和存储密集型应用可以实现更高的执行效率。

2. 专属资源使用: 用户获得专属的物理服务器资源，这意味着不会有“邻居”干扰，保证了更稳定的计算和存储性能。

3. 灵活配置: 根据不同的应用需求，用户可以选择最适合的硬件配置，包括处理器、内存、存储和网络资源等，以实现最优的性能与成本平衡。

4. 即时可用性: 与传统的物理服务器部署相比，裸金属算力平台能够提供更快的部署速度，让用户能够迅速启动项目，缩短项目上线时间。

5. 安全与隔离: 由于用户对硬件资源具有完全的控制权，这提供了更高级别的安全性和隔离性，尤其适合对安全性和合规性要求较高的业务场景。

BMCP平台是面向未来的企业级解决方案，适合需要处理大规模计算任务的科研机构、智能计算任务、大型互联网公司和金融行业等，为他们提供了一个既强大又灵活的计算环境。

# 3.应用场景

BMCP提供通用和利旧两种场景，针对不同项目的IDC环境，BMCP在利旧场景提供极致兼容性，在通用场景提供极致性能。

**通用场景**

BMCP基于原生RoCE高网和高性能并行文件存储，构建出具有高扩展性、高性能、高性价比的高性能算力集群服务。向上采用面向AI场景深度优化的ACK容器集群服务，提供硬件加速、调度优化、网络拓扑感知等多项能力。BMCP提供智算高网、智算基础、智算纳管、高性能计算高网等多种实例类型，以满足不同行业不同用户对于算力的多样化需求。以极致的性价比，帮助用户构建云上AI应用。

**典型场景**

- 大规模分布式训练：大规模+高性能+高资源利用率，提供深度优化的智能计算服务，适用于图形图像处理（如AIGC图像生成）、自然语言处理（如AIGC文本生成）、语音和视频等应用领域，确保高效且可预期的训练服务，从而加速模型迭代效率。

- AIGC：提供AIGC场景化解决方案，辅助文案、图像、音视频等数字内容生成。

- 自动驾驶：提供裸金属、容器、虚拟化多种算力类型，通过多种GPU资源调度策略、RDMA网络和CPFS存储系统，确保高效的数据处理和计算能力。支持自动驾驶场景PB级数据下模型高效训练，助力自动驾驶特有的感知、规控、仿真生成等全链路相关算法深度优化和快速迭代。

- 科研智算：提供AI&HPC融合算力，统一网络共享算力及存储资源，通过对人工智能和高性能计算任务的统一部署与调度，为基础科研、新药研发、工程仿真等领域提供统一的标准化计算服务，促进科研新范式的创新。

**利旧场景**

纳管形态主要面向用户的存量资源复用的需求，即在用户现有的超智算中心IDC环境中，通过飞天企业版BMCP接入用户算力服务器，实现对高性能算力集群的纳管。此举旨在统一管理客户分散的算力资源，从而最大化客户的历史投资回报。同时，通过阿里云容器、机器学习平台等产品，构建软硬件一体的产品化解决方案，帮助用户实现“智算上云”，提升整体平台的服务能力。
